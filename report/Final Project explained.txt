Count healthcare incidents from 2020–2023
Determine how many healthcare ransomware incident records exist for each year between 2020 and 2023.


python -c "import pandas as pd; df=pd.read_csv('data/raw/incidents.csv'); df['incident-date']=pd.to_datetime(df['incident-date'],errors='coerce'); h=df[(df['sector']=='Healthcare') & (df['incident-date'].dt.year.between(2020,2023))]; print(h['incident-date'].dt.year.value_counts().sort_index()); print('Total candidates:',len(h))"

Inspecting dataset Schema

python -c "import json; data=json.load(open('data/raw/schema.json',encoding='utf-8')); print('Schema sections:',list(data.keys()))"

Output:

Schema sections: ['$schema', 'title', 'type', 'properties', 'required', 'additionalProperties', '$defs']

Output meaning: The shema consist of 7 main sections

Section			Meaning
$schema			JSON Schema standard being used
title			Name or title of the schema
type			Expected type of the data
properties		Definitions of the dataset fields
required		Fields that must be present
additionalProperties	Whether fields outside those defined are allowed

$defs			Reusable definitions referenced elsewhere in the schema
